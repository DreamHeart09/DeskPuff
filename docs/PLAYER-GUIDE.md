## 第一次玩

### 找到菜单栏里的 DeskPuff

[从源码构建并启动应用](../README.zh-CN.md#开始游玩)后，点击 macOS 菜单栏里的 DeskPuff 图标。在**桌面与物件**中确认**桌面**设为**显示**，先用**自由摆放**。你可以随时切换桌面显示。首次游玩无需账号，进度保存在本机。

### 从盒里抽一支烟

1. 点击烟盒盒身，等盒盖打开并露出烟支。
2. 从盒口拖出一支烟，松开后可以拖烟身中部来移动，或拖任一端附近来旋转。
3. 双击打火机机身点火。抓住机身把火苗移到烟头，看到烟头亮起后，把打火机移开并再次双击关闭火焰。
4. 按住点燃的烟身片刻，再松开，观察烟雾。等烟头积了灰，双击烟身把灰弹下去。
5. 想停下来时，右键点香烟，选择**掐灭香烟**。手边有烟灰缸时，也可以把燃烧端放进缸内。

下一步可以[试试桌面物理](#桌面物理实验)，或[用背包接一次灰](#回收与合成)。

## 操作速查

| 想做什么 | 怎么操作 |
| --- | --- |
| 打开、关上烟盒 | 点击盒身。打开后从盒口拖出烟支。 |
| 移动、旋转烟盒 | 拖动盒身来移动，拖右下角把手来旋转。 |
| 把烟装回盒里 | 把未点过、未受损的烟对齐开着的盒口，拖进空槽。 |
| 移动、旋转香烟 | 拖中段来移动，抓住靠近两端的位置来旋转。 |
| 打开、关掉火苗 | 双击打火机机身，避开火力调节区。 |
| 吸一口、弹灰 | 点燃后按住再松开可吸一口。等烟头有灰后，双击弹灰。 |
| 熄灭香烟 | 右键选择**掐灭香烟**，或把燃烧端放入烟灰缸。 |
| 开启重力 | 菜单栏 → **物理模式** → **自然下落**。切回**自由摆放**继续手动布置。 |
| 移走桌面物件 | 菜单栏 → **桌面** → **隐藏**。需要收纳单件物品时，使用物件的右键菜单或背包。 |
| 放出桌面背包 | 右键点击 DeskPuff 菜单栏图标，选择**把背包放到桌面**。 |

## 桌面物理实验

### 窗口接灰

打开普通的 Finder 窗口，移到桌面中间。把已有积灰的香烟移动到窗口顶边正上方，双击弹灰，观察一部分碎屑是否留在上沿。再挪到窗边之外试一次。建议先用**自由摆放**，让两次操作只有落点不同。

### 烟雾扰动

点燃后先让香烟停在原地，等烟流出现。抓住烟身中段向一侧拖动，再停下来，比较旧烟流和新烟流。背景越平整，对比越容易看清。烟太快散掉时，可在菜单栏调整**消散**。

### 下落与碰撞

把**物理模式**切到**自然下落**，抓住烟身拖离屏幕底部，再松手。试第二次时保持相同高度，先旋转一点，观察落下和接触的差别。要观察折痕，可另外让烟身斜向撞到屏幕边缘，等停下后看受力处。

## 回收与合成

### 把地上的灰收进背包

1. 右键点击菜单栏图标，把背包放到桌面上。
2. 将袋口摆在落灰路径上，或拖动背包，让袋口扫过桌面上散落的灰。
3. 看背包的收取提示。右键提示可回收的烟头也能拖到袋口。遇到空间提示时，先打开背包整理格位。

### 做一次合成

1. 从菜单栏打开**背包**进入玩家中心，切到**回收**，打开**自由合成工坊**。
2. 选择两种已有材料，先各投一份。留意预计产物、件数，以及会丢弃的多投材料。
3. 看清预览后确认，去图鉴查看首次发现。如果预览显示**一坨灰**，可以调整材料组合，也可以把它做出来。
4. 合成品可以留下或出售。卖掉一件藏品，图鉴里已经解锁的记录仍然保留。

空盒按具体款式区分。投入还有余量的烟盒时，盒里剩余烟支会一起消耗。想探索配方，可以先从游戏内预览和已有材料开始尝试。

## 收藏布置与成长

| 入口 | 在这里做什么 |
| --- | --- |
| **档案** | 看段位、星级、晋级进度和收入记录。使用香烟可以增进度，段位对应周期津贴。 |
| **背包** | 管理桌面物件、材料和收藏。摆出或收回物件，为合成和购物腾出格位。 |
| **商店** | 选购补给、桌面物件和外观。结账前留意余额与背包空间。 |
| **回收** | 试配方、查看已解锁图鉴、回收不想留在背包里的藏品。 |

## 设置与常见问题

- **桌面上没有物件。** 先确认菜单栏里的**桌面**设为**显示**，再到背包看看要用的物件是否已摆放。
- **点不着。** 检查打火机是否有火，移动打火机让火苗确实靠近烟头。双击机身时避开火力调节区。
- **烟太多，或想让烟显示在窗口后面。** 在菜单栏调整**消散**和**烟雾显示**。进游戏设置调烟雾浓度或打开**节能渲染**。浓度与画质是独立选项。
- **本地构建打开时出现安全提示。** 本地包使用临时签名。对可信源码构建的应用，按当前 macOS 提供的打开流程操作，详见[构建与打包](BUILD-AND-PACKAGING.md)。
- **找不到小组件。** 小号与中号组件用于展示段位、余额和进度。构建包需先嵌入扩展，启动应用后再检查小组件图库。图库可见性与共享快照仍需在目标 Mac 验证。
- **存档在哪里。** 游戏状态与偏好保存在本机。退出或删除应用本身可能保留本地数据，目前没有账号云同步。
