# Contributing to DeskPuff

Contributions of code, documentation, tests, gameplay feedback, and original style packs are welcome.

## Getting started

1. Fork the repository and create a focused branch.
2. On macOS 14 or later with Apple Silicon, run `swift test` and build with the instructions in [Build and packaging](docs/BUILD-AND-PACKAGING.md).
3. Open a pull request describing the change and how you verified it. Include screenshots or a short recording for user-facing changes.

## Code contributions

- Submit code you own or are authorized to contribute.
- Project code contributions are provided under [GPL-3.0-only](LICENSE). Preserve existing copyright and license notices.
- Disclose third-party code and dependencies, including their source, version, license, and required notices.
- Contributors retain their copyright. No CLA or copyright assignment is required.

## Art and media

- Submit only assets you have the right to contribute and redistribute.
- Include the creator or rights holder, source, license, attribution, and any modifications.
- Confirm the license for each asset before it is merged; no default asset license is implied.
- Do not submit third-party photos, trademarks, or branded packaging without the required permissions.

## Pull requests

Keep changes focused, describe any compatibility or licensing impact, and report the checks you ran. For bug reports, include your macOS version, Mac model, reproduction steps, and relevant screenshots or logs.
